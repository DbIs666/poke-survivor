# P0 级页面生成任务提示词

## 🎯 主控提示词（给主 AI 使用）

```
我需要你作为主控 AI，协调多个 subagent 完成 PokéSurvivor 网站的 P0 级页面创建任务。

**项目背景**：
- 这是一个 PokéSurvivor 游戏的粉丝攻略网站
- 使用 Astro 7 + TypeScript，部署在 Cloudflare Pages
- 已有页面：首页、如何游玩、最佳宝可梦、排行榜、传说裂隙、合作模式、移动端指南、宝可梦图鉴
- 支持英文和中文（繁体）双语

**你的任务**：
1. 阅读项目文档：
   - `page-expansion-plan.md`（页面扩展计划）
   - `CLAUDE.md`（开发规范）
   - `src/pages/index.astro`（页面结构参考）
   - `src/layouts/BaseLayout.astro`（布局模板）

2. 为以下 P0 级页面分别派发 subagent：
   - 阿尔宙斯审判模式专题 (`/arceus-judgment/`)
   - 招式融合系统 (`/fusion-bonds/`)
   - 招式图鉴与进化路径 (`/moves/`)

3. 每个页面需要按照以下流程执行（通过 subagent）：
   - **阶段1：资料搜索** → 收集官方信息
   - **阶段2：资料整理** → 结构化数据
   - **阶段3：真实性验证** → 对照官方来源
   - **阶段4：相关度检查** → 确保内容与游戏版本匹配
   - **阶段5：内容生成** → 编写页面代码
   - **阶段6：去 AI 味** → 优化语言风格
   - **阶段7：主控验收** → 你来最终检查

**工作流程**：
- 每个页面使用一个 subagent 完成完整流程
- Subagent 需要按阶段输出中间结果
- 你在每个阶段后进行审查，批准后再进入下一阶段
- 最终你需要验收所有页面的质量

**开始执行**：
请先阅读 `page-expansion-plan.md`，然后为第一个页面（阿尔宙斯审判模式）启动 subagent。
```

## 📋 完整执行顺序

当主控 AI 收到此提示词后，应该：

1. **读取文档**：
   ```
   先阅读 page-expansion-plan.md 了解任务背景
   ```

2. **启动第一个 Subagent**（阿尔宙斯模式）：
   ```
   使用 Agent 工具创建 subagent，传入上述完整的 7 阶段提示词
   ```

3. **逐阶段审查**：
   ```
   Subagent 完成阶段1后，主控审查结果
   - 如果通过：批准进入阶段2
   - 如果不通过：提出修改意见，要求重做
   ```

4. **最终验收**：
   ```
   检查页面的：
   - 内容质量（准确性、实用性）
   - 代码质量（符合规范、无错误）
   - SEO 优化（关键词、结构化数据）
   - 用户体验（可读性、设计）
   ```

5. **批准或退回**：
   ```
   - 通过：合并到项目，开始下一个页面
   - 不通过：明确指出问题，要求修改
   ```
