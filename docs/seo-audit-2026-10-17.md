### 2. **Fabricated Statistics — zh/pokedex 最嚴重**

#### zh/pokedex — Multiple lines
**Claim**: "數值來自官方檔案" (stats from official files)  
**Evidence**: ALL stat multipliers (×1.09 Scorbunny, HP 110 Slowpoke, ×1.51 Haxorus, 138 speed Dragapult, 128 Garchomp) **DO NOT EXIST** in:
- Official guide (pokesurvivor.com/en/guide/)
- Official Pokédex (pokesurvivor.com/en/pokedex/)
- pokemon.json (has no HP/speed/attack fields)

**Fix**: 
- **DELETE** all stat multipliers, OR
- **RELABEL** as "本站測試" / "玩家估計" / "社群觀察" (NOT "官方檔案")
- **DELETE** the claim "數值來自官方檔案"

#### Unverifiable mechanics across multiple pages:
- **Personality quiz with reject option** — no official source
- **30-minute Arceus phase** — verified (OK)
- **Higher spawn rate for undefeated legendaries** — no official source
- **Rift rewards "bonds and coins"** — official page only says "reward"

## Conclusion

Overall site quality is **strong** (91.2/100 average) with excellent technical SEO implementation. Main weaknesses:

1. **Authenticity issues**: Too many unverified/fabricated numeric claims
2. **Source attribution gaps**: Need explicit code citations or "fan-tested" labels

**Strengths**:
- Excellent technical foundation (hreflang, canonical, structured data, sitemap)
- Comprehensive coverage (all major game features covered)
- High accuracy on verified facts (most claims checked out)
- Good user experience (clear hierarchy, breadcrumbs, internal links)

**High-ROI fixes**:
1. zh/pokedex stat relabeling (biggest credibility issue)
2. Gacha ticket contradiction resolution (affects user trust)
3. Keyword stuffing cleanup (affects rankings)
4. Missing Slowpoke stats and healer % correction (small but visible errors)
